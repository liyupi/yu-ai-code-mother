## 如何核验

- 使用 `git log --format=fuller` 查看完整提交与作者记录。
- 使用 `git blame <file>` 查看具体文件的行级来源。
- 以各次提交差异作为个人实际修改范围，不以仓库所有权替代作者权归属。
